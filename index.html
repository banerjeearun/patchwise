PatchWise security advisory triage for Python
snapshot 2026-11-05· 392 advisories · 1,345 releases

PatchWise checks pinned Python dependencies against known security advisories. Paste a requirements.txt, or ask about one package and a CVE. You get which advisories affect your versions, the smallest upgrade that fixes them, and what changes on the way, with links to the release notes.

Covers django, urllib3, pillow, aiohttp, starlette and cryptography. Anything else is listed as not checked, which doesn't mean it's safe.
